AI 교무실 설명서

Claude Cowork나 Claude Code에 맡긴 일이 지금 어떤 상태인지 1~5층짜리 도트 교무실로 보여주는 앱이에요. Claude가 질문이나 결재가 필요하면 팀장이 교무실 문 앞에서 기다려요.

준비물1 폴더2 API 키3 앱 설정4 Claude 연결5 위젯·화면문제 해결

준비물

  • Claude 유료 요금제 (Cowork 또는 Claude Code 사용)
  • PC에 설치한 구글 드라이브 데스크톱 앱
  • 구글 API 키 (2단계에서 만들어요. 제미나이 API 키가 있으면 그걸 써도 돼요)

1단계. 드라이브에 상태 폴더 만들고 링크 공유하기

  1. PC 파일 탐색기에서 Google Drive (G:) > 내 드라이브에 Claude상태 폴더를 만들어요.
  2. 웹 브라우저에서 drive.google.com에 들어가 그 폴더를 오른쪽 클릭 > 공유 > 공유.
  3. 일반 액세스를 "링크가 있는 모든 사용자"로 바꾸고 권한은 뷰어로 둬요.
  4. 링크 복사를 눌러 메모해 둬요. 3단계에서 앱에 넣어요.

링크를 아는 사람은 상태 파일을 볼 수 있어요. 그래서 연결 규칙에 "학생 이름 같은 개인정보는 쓰지 않는다"가 들어 있어요.

2단계. 구글 API 키 준비하기

앱이 드라이브 폴더를 읽으려면 Google Drive API가 켜진 구글 API 키가 필요해요. 무료이고 결제 정보 없이도 돼요.

제미나이 API 키가 이미 있을 때

  1. console.cloud.google.com에서 위쪽 프로젝트 목록에서 제미나이 키가 들어 있는 프로젝트를 골라요.
  2. API 및 서비스 > 라이브러리에서 Google Drive API를 검색해 사용.
  3. API 및 서비스 > 사용자 인증 정보에서 그 키를 눌러, API 제한사항이 "키 제한"이면 Google Drive API도 체크하고 저장.

키가 없을 때 (새로 만들기)

  1. console.cloud.google.com > 프로젝트 선택 > 새 프로젝트 > 이름 ai-gyomusil > 만들기
  2. API 및 서비스 > 라이브러리에서 Google Drive API > 사용
  3. API 및 서비스 > 사용자 인증 정보 > 사용자 인증 정보 만들기 > API 키
  4. 키 수정 > API 제한사항 > 키 제한 > Google Drive API만 체크하고 저장
  5. 키(긴 영문·숫자)를 복사해 메모해요.

API 키는 이 핸드폰 앱 안에만 저장돼요. 다른 사람에게 보내거나 공개된 곳에 적지 마세요.

3단계. 앱 설정하기

사무실 이름화면 맨 위 제목. 예: 도덕후 AI 교무실
폴더 공유 링크1단계에서 복사한 링크
구글 API 키2단계에서 준비한 키
층 수1~5층 중 선택
층 이름층마다 부서 이름. 예: 1F 교과연구부
파일 이름표층마다 다른 짧은 단어. 예: 수업, 담임, 업무
Claude 작업 주소선택. 비우면 층을 눌렀을 때 Claude 앱이 열려요

파일 이름표가 수업이면 그 층은 상태_수업.json 파일을 읽어요. 긴 링크와 키는 PC 카톡 "나와의 채팅"으로 보내 복사·붙여넣기 하면 편해요.

4단계. 층마다 Claude 연결하기

층마다 그 일을 맡을 Claude에게 상태를 기록하는 방법을 알려 줘요. 앱 ⚙ 설정의 층 칸에 복사 버튼이 두 개 있어요.

Cowork로 일할 때

  1. 그 층 일을 맡길 Cowork 작업을 열고 Claude상태 폴더를 연결해요.
  2. 앱에서 그 층의 Cowork용 규칙 복사를 눌러요.
  3. Cowork 메시지 칸에 붙여 넣고 보내요. Cowork가 폴더 연결을 확인하고 연결 테스트 기록을 남겨요.

Claude Code로 일할 때

  1. 그 층 일을 하는 폴더(프로젝트)에서 Claude Code를 열어요.
  2. 앱에서 그 층의 Claude Code용 설정 복사를 눌러요.
  3. Claude Code에 붙여 넣고 보내요. Claude Code가 훅(hooks)을 설정해서, 지시를 보낼 때·권한을 기다릴 때·답이 끝날 때마다 자동으로 상태를 기록하게 돼요.
  4. 훅은 Claude Code 프로그램이 직접 기록해서 빼먹는 일이 없고, 사용량도 들지 않아요.

1분쯤 뒤 앱 아래 상황판에 "작업 끝 · 연결 테스트"가 보이면 그 층은 연결 끝이에요. 같은 층 일을 PC 두 대에서 나눠 하면 서브 PC 쪽은 상태_이름표_서브.json에 쓰게 해요. 앱은 둘 중 더 급한 쪽(결재 > 질문 > 작업 중 > 끝)을 보여줘요.

5단계. 위젯 놓기와 화면 보는 법

바탕화면 빈 곳을 길게 눌러 위젯 > AI 교무실을 놓고 크기를 맞춰요. 위젯은 약 3분마다 새로 고쳐지고, 오른쪽 아래 ↻를 누르면 바로 새로 고쳐져요.

문제 해결

  • "API 키나 폴더 공유 설정을 확인해 주세요": Google Drive API를 켰는지, 폴더를 "링크가 있는 모든 사용자"로 공유했는지 확인해요.
  • "폴더를 찾을 수 없어요": 넣은 링크가 폴더 링크가 맞는지, 공유를 켰는지 확인해요.
  • 층이 계속 "자유 시간": 파일 이름표와 Claude가 쓴 파일 이름이 같은지 봐요.
  • 늘 질문 대기: 상태 파일이 waiting으로 남은 거예요. 그 Claude에게 "상태 파일을 done으로 바꿔 줘"라고 해요.
  • 반영이 느려요: 보통 1분 안팎 걸려요. PC 구글 드라이브 동기화가 일시중지되지 않았는지 확인해요.
